# game/ (O3DE project, created in M0)

This folder is reserved for the O3DE project `WaveArena`. It is created with the o3de CLI in M0, not generated by hand. Plan a separate evening: the first build is long and needs a lot of disk space (budget 60+ GB for engine, build and cache).

## 1. Install the toolchain

1. Visual Studio 2022 with the **Desktop development with C++** workload (MSVC v143, Windows SDK).
2. CMake (the version listed on the O3DE requirements page).
3. O3DE latest stable from https://www.o3de.org/download/ (installer), or from source if you want to step into engine code.
4. Check the requirements page for current versions: https://www.o3de.org/docs/welcome-guide/requirements/

Write the exact versions into `docs/learning/M0.md`.

## 2. Create the project

From the repository root (PowerShell). `o3de.bat` lives in `<O3DE install>\scripts\`.

```powershell
# game/ must not contain anything but this README. Move the README out first if the CLI refuses a non-empty folder.
& "<O3DE install>\scripts\o3de.bat" create-project --project-path .\game --project-name WaveArena
```

The default template creates a project Gem inside `game/Gem/` (code in `Source/`, public headers in `Include/WaveArena/`). The exact layout depends on the template version: write down what you got.

## 3. Configure and build

```powershell
cmake -B game\build\windows -S game -G "Visual Studio 17"
cmake --build game\build\windows --target WaveArena.GameLauncher Editor --config profile -- /m
```

Then open the Editor from `game\build\windows\bin\profile\Editor.exe`, or through Project Manager.

## 4. Add a trivial component to prove the Gem works

Add `HelloComponent` (logs a line in `Activate`), register it in the Gem module, rebuild, and check that it appears in the Editor's Add Component menu. See `.claude/skills/o3de-component/SKILL.md` for the checklist.

## 5. What gets committed

Commit: `project.json`, `CMakeLists.txt`, `Gem/`, `Levels/`, `Prefabs/`, `Registry/`, `Config/`, `ShaderLib/` and other sources the template creates.

Never commit (covered by `.gitignore`): `build/`, `Cache/`, `user/`, `*.vs`.
