# Code style (general)

- English for code, comments, commits and docs.
- Small functions, clear names, no clever tricks. Comments explain why, not what.
- No dead code, no commented-out code, no TODO without an issue number.
- Files over about 400 lines or classes with more than one reason to change get split.
- Language specific rules: `python.md` (backend, infra, tools, analytics) and `cpp-o3de.md` (game).
