# Writing docs

- English, short sentences, tables for comparisons.
- Never use long dashes (em dash or en dash). Use commas, colons, parentheses or a plain hyphen. A hook and CI enforce this.
- Milestones live in docs/ROADMAP.md and always have acceptance criteria as checkboxes. Tick them in the PR that delivers them.
- Significant decisions get an ADR in `docs/adr/NNNN-title.md` (Status, Context, Decision, Consequences) and a row in `docs/adr/README.md`.
- Learning notes: `docs/learning/Mn.md` from the template. Lessons worth showing in an interview go to the "What I learned" table in README.md with a link to the commit or PR.
- Link to official docs (o3de.org, docs.aws.amazon.com) rather than blog posts.
